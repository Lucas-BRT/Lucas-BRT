## What I build

- **Rust systems and CLIs:** on-device tooling, simulation, procedural generation, desktop apps.
- **Backend APIs:** Axum, SQLx, OpenAPI (utoipa), TypeScript/Node.
- **Web:** React, TypeScript, Tailwind.
- **Linux desktop:** COSMIC, NixOS, Zed, tooling that makes the daily setup reproducible.
